# Data Versioning (DVC) Notes

## 1. Data Source
This synthetic dataset is generated by `make_data.py` for robotaxi ETA prediction.
- Features: `distance_km`, `traffic_index`, `weather` (0=Sunny, 1=Rainy, 2=Snowy), `is_peak` (0=Off-peak, 1=Peak)
- Target: `eta_min`
- Raw data will not be committed to Git. Large data files are stored on Azure Blob Storage and tracked by DVC.

## 2. Version Differences
- **v1.0 (Baseline)**: Original generated dataset with 100 records.
- **v2.0 (Improved)**:
  1. Outlier cleaning: Drop unreasonable samples, e.g. trips shorter than 5km but ETA over 40 mins.
  2. Fix long-tail bias: Add 15 rainy peak-hour samples (ETA +30%) and 15 snowy peak-hour samples (ETA +60%). This balances the dataset and helps the model perform better under extreme weather.

## 3. Code & Data Mapping
Git commits are linked to DVC data versions for reproducibility.
- Dataset **v1.0**: Tracked in the initial DVC commit.
- Dataset **v2.0**: Tracked in the commit with `make_v2_data.py`, tagged `v2.0`.

Run `dvc pull` to download the latest dataset from Azure.
