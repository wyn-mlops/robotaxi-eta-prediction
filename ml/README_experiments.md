# 模型实验追踪报告 (Model Experiment Tracking)

本项目使用 **MLflow** 对模型训练进行了实验追踪。实验记录存储于本地 `mlruns` 数据库及远程追踪服务。

## 1. 实验指标 (Metrics)
我们选择 **MAE（平均绝对误差）** 作为核心优化指标。
*   **为什么选 MAE**：因为我们的任务预测的是“萝卜快跑的预计到达时间（分钟）”。MAE 直接代表了预测时间与实际时间平均相差多少分钟。对用户而言，“误差 0.75 分钟”比抽象的准确率更直观、更易于理解。

## 2. 实验对比 (Baseline vs Improved)
我们在相同的 v1 数据集上对比了两个模型：
*   **Baseline_Linear（基础模型）**：线性回归模型。训练速度极快，在本线性合成数据上表现优异，MAE = **0.75 分钟**。
*   **Improved_RandomForest（改进模型）**：随机森林回归模型。非线性拟合能力强，但在当前小样本 Toy Data 上可能出现了轻微过拟合，MAE = **2.89 分钟**。

## 3. 生产模型选择 (Production Model)
**结论：我们选择 `Baseline_Linear` 作为最终上线的生产模型。**
*   **原因**：在本次 Toy Data 实验场景下，基础模型的误差远小于改进模型。这证明了在工业界：**模型并非越复杂越好，最适合当前数据特征的模型才是最好的。**
*   **复现步骤**：运行 `python train.py` 即可重新触发实验并记录到 MLflow。
